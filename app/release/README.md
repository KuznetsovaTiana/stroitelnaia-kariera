# Статическая сборка

Архив stroitelnaia-kariera-static-2026-10-14.zip содержит готовые index.html и assets/ в корне. Распаковать в корень выбранного статического размещения или подпапку. Hash-маршруты не требуют SPA fallback; base ./ поддерживает подпапку. Сервер должен отдавать JS как text/javascript, CSS как text/css, HTML как text/html. Проверено обычным локальным HTTP-сервером в /demo-preview/.

Не открывать двойным щелчком через file://. Для локального просмотра из app: npm.cmd run preview -- --port 4175 --strictPort. Файлы и SHA-256 записаны в manifest.json. При новой сборке создавать новый архив/манифест и повторять приёмку.

Публикации/хостинга/QR нет. Инструкция и результаты: ../../docs/acceptance-results.md, ../../docs/jury-demo.md. Реальные данные, внешняя авторизация и интеграции отсутствуют. Сохранение локальное и раздельное для каждого origin браузера.
