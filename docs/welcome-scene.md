# Живая архитектурная сцена приветствия

Дата: 16.10.2026. Источник: прямое задание заказчика и три предоставленных PNG. Работает локально средствами React, SVG и Web Animations API; без видеогенерации, внешних запросов и новых зависимостей.

## Исходники и регистрация

Три предоставленных файла сохранены без изменений в source/assets/welcome-scene-*-original.png. Runtime WebP: drawing 249008 байт, construction 260722, completed 252370. Общий кадр 1672×941, равномерное вписывание с центрированием; небольшая разница исходной ширины компенсируется молочным краем, фасады не деформируются. Оптимизатор app/scripts/optimize-welcome.mjs использует браузерный WebP quality .9.

По исходникам визуально сравнены верх левой башни, центральная линия крыш, верхняя грань правого корпуса и передний прямоугольный бордюр. Все три фотографии и SVG занимают один architecture-frame. SVG viewBox=0 0 1672 941, preserveAspectRatio=xMidYMid slice соответствует img object-fit:cover/object-position:center. На телефоне изменяется только общий frame, все четыре слоя масштабируются/кадрируются вместе. На портретном мобильном кадре двор поднят над подписью команды и ослаблен молочный градиент в зоне движения.

## Таймлайн

Один общий конечный таймлайн 14800ms:

| Время | Состояние |
|---|---|
| 0–850ms | Мягкое проявление растра чертежа, без заявления о рисовании каждой линии |
| 850–2100ms | Чертёж удерживается |
| 2100–4600ms | Мягкое растворение в строительство, без сканирующей границы |
| 4200–8650ms | Появление, короткие маршруты и исчезновение строительных SVG |
| 8800–11800ms | Растворение в готовые фасады и благоустройство |
| 11800–14800ms | Короткий проход одного дополнительного жителя; затем полная остановка |

У машины вращаются колёса; у работников и жителя чередуется небольшой угол ног. Непрерывных циклов нет. Растровый кран, техника и люди не вращаются и не перемещаются.

## Управление и жизненный цикл

Рядом с «Выбрать роль» — две компактные кнопки с доступными названиями и tooltip: «Приостановить/Продолжить анимацию», «Повторить анимацию». Клавиатурный фокус штатный; пауза проверена клавишей Space. Все WAAPI-эффекты имеют одинаковую длительность и общий startTime, поэтому пауза/повтор/видимость синхронны. visibilitychange ставит на паузу и продолжает с того же времени; ручная пауза не отменяется восстановлением вкладки. После финала пауза недоступна, повтор доступен.

При размонтировании все Animation.cancel() и обработчики visibilitychange/matchMedia удаляются. При reduced motion — готовый комплекс без SVG-движения, управление анимацией отключено. Если недоступен хотя бы один слой — статичный лучший доступный кадр, без сломанной последовательности. До готовности всех слоёв показывается загруженный статичный чертёж или молочный фон; готовый комплекс не вспыхивает перед возвратом к чертежу. Кнопка выбора роли не ждёт загрузки.

## Упрощения и границы

Встроенные в PNG объекты оставлены неподвижными. Их удаление с гарантией сохранения пиксельной геометрии и фактуры двора не выполнялось; прямоугольных заплаток нет. Анимированы только отдельные дополнительные SVG на других свободных участках. Трос/груз не добавлялись: убедительное совмещение с нарисованной стрелой и безопасный маршрут груза не обеспечены. Это стилизованная ожившая иллюстрация, не физическая симуляция или видео реальной стройки.

Сохранена фактически действующая навигация DEC31/33: логотип кабинета ведёт домой роли, логотип entry-экранов — на приветствие; неоднократно повторённое во вложениях прежнее описание не использовано для побочной смены маршрутов. Предыдущая читаемость, команда «Вектор развития», CASE-IN и отсутствие прокрутки при обычном масштабе сохранены. При увеличенном тексте допускается естественный рост, без обрезания.

## Проверки

Команды из app/: npm.cmd run typecheck, lint, build, test, test:entry, test:welcome. test:welcome проверяет статические кадры на 1440×900, 768×1024, 430×932, 390×844, 360×640, 320×568, 844×390; совпадение frame фотографий/SVG, отсутствие прокрутки при обычном масштабе, изменение координат машины и колёс, скрытие строительных объектов перед благоустройством, Pause/Resume/Replay, очистку ВСЕХ сохранённых Animation-объектов при уходе, reduced motion, ошибки каждого файла, задержанную загрузку и эмуляцию visibilitychange.

Отдельно выполняется полный цикл в реальном времени до finished (14.8s), после чего все эффекты имеют playState=finished. Основные стадии desktop1440/mobile390 открыты в браузере и просмотрены на скриншотах docs/previews/scene-{drawing,construction,finishing,residents,final}-*.png. Полноценный WebM не записан: Playwright требует отсутствующий ffmpeg-1013/ffmpeg-win64.exe. Реальное устройство/Safari не проверены.
