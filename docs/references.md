# Источники и границы достоверности

## Основание комплекта

1. Предоставленный исходный файл «Техническое задание.docx», версия 1.0 от 12.10.2026. Сохранён без изменений как [original-spec.docx](../source/original-spec.docx); текстовая копия рядом.
2. Прямые уточнения заказчика в обсуждении: демонстрация, моковые данные, только студенты МГСУ, ограничения сценариев, отсутствие реальной подписи и модели, доступ по QR, экономный запуск, визуальное направление.
3. Рабочая конкретизация: типы, статусы, маршруты, объём seed, технический стек, формулы подбора, этапы разработки. Эти решения выделены в [реестре](decisions.md), не представлены как точная цитата заказчика.

## Функциональный ориентир hh.ru

Исходное ТЗ использует hh.ru для знакомых сценариев поиска, компаний, резюме и откликов. В комплекте не заявляется доступ к закрытой внутренней архитектуре hh.ru. Собственные процессы практик, сведения вуза и документы проектируются из задач нашего продукта.

Официальные отправные страницы для последующей проверки:

- https://hh.ru/
- https://hh.ru/employer
- https://hh.ru/employers_list
- https://feedback.hh.ru/

Ссылки здесь не означают повторную проверку актуального интерфейса при сборке этого комплекта. При новом сравнении фиксировать дату, URL и конкретное наблюдение. Не переносить бренд, тексты или уникальные композиции hh.ru.
