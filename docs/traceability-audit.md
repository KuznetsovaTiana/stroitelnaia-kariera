## Рабочие решения C

- Дополнительные сотрудники — персонажи основной роли «Компания», не новые основные роли. Владелец остаётся доступным; оператор не отключает сам себя. Перечень назначений и подроль сохраняются в общем состоянии.
- Тестовый импорт принимает только JSON с `demoOnly: true` и учебными ID; ограничен 100 KiB / 100 строками. Предпросмотр не применяет данные. Пользователь явно подтверждает допустимые строки, внешний ID даёт upsert без дублей.
- Новое дело фиксирует версию требований и набор шаблонов; документы хранят заполненный текст и выбранные поля. Изменение шаблона не меняет ранее созданный файл.
- Свободное пояснение правил завершения — текст для человека. Исполняются фиксированные доменные условия документов/заданий/отчёта/решения координатора; произвольный текст не исполняется как программа.
- Симуляция O10 выполняет только локальную операцию и пишет журнал успеха/контрольной ошибки. Никакой интерфейс не считается реальной интеграцией.
- Деактивация справочника сохраняет исторические ссылки, исключая выбор для новой карточки. Скачивание CSV/HTML выдаёт файл действительного формата.

Существенных конфликтов с позднейшим scope не обнаружено. Требования промышленного исходника не объявлены реализованными. Следующее действие — D: закрыть явно отмеченные пробелы проверки coverage и полный SC10 до отдельного решения о публикации.
