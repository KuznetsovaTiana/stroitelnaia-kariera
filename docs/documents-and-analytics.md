# Документы и аналитика

## Учебные документы

Первая версия поддерживает четыре типа: образец договора о практике, направление, индивидуальное задание, отчёт. Все имеют видимую надпись «Демонстрационный учебный образец. Не предназначен для реального оформления». Содержание — вымышленная форма для показа автозаполнения, не утверждённая форма МГСУ и не юридическая рекомендация.

Общие поля: студент, вуз, компания, вид практики, период, объём, учебные задачи, руководители, дата формирования, номер версии. Источники полей показываются в редакторе. Недостающие поля подсвечиваются; нельзя выдать документ с оставшимися `{{переменными}}` за готовый.

| Тип | Когда нужен | Кто заполняет и проверяет |
|---|---|---|
| Образец договора | До начала практики | Студент запускает заполнение, компания проверяет свои сведения, координатор согласует учебную версию |
| Направление | До начала практики | Автозаполнение из дела, проверка координатором |
| Индивидуальное задание | До начала практики | Учебные результаты от координатора, задачи от компании, студент знакомится |
| Отчёт | В конце практики | Студент заполняет, компания даёт отзыв, координатор фиксирует результат |

Договор в демо относится к выбранному делу и позволяет показать поля сторон. Реальная договорная схема между вузом и организацией — отдельное проектирование после появления партнёров.

Минимальный маршрут: подготовить → проверить → вернуть с замечаниями либо согласовать. Для договора допустимы два последовательных шага company → university; общий статус approved только после обоих. У документа хранить `reviewSteps` с исполнителем, версией и решением. Студент не может согласовать собственный документ. Изменение после согласования создаёт новую версию и сбрасывает решения только для новой версии.

Скачивание должно выдавать реальный файл с заполненными данными. Рабочий минимум — самостоятельный HTML для печати и сохранения браузером в PDF, с понятными подписями «Скачать образец HTML» и «Печать / сохранить PDF». Не называть HTML файлом DOCX/PDF. Если выбран клиентский генератор PDF, отдельно проверить кириллицу, переносы страниц и размер библиотеки. Файлы формируются по запросу; не хранить бинарные копии в localStorage. Шаблоны и версии хранятся как компактный текст/поля.

## Показатели

Все графики подписаны «Демонстрационные данные», указан период и размер выборки. Аналитика строится из сущностей и событий. Исторические seed-события и новые visitor-события различаются; можно переключать «Весь демо-набор» / «Действия в этой демонстрации».

| Показатель | Определение |
|---|---|
| Кадровые запросы | Число published-предложений на выбранную учебную дату; распределение по направлениям, регионам и типам |
| Запрос навыков | Число уникальных предложений, где навык указан; один навык в одном предложении считается один раз |
| Вместимость практик | Сумма capacity выбранных опубликованных практик; рядом занятые и свободные места |
| Обеспеченность местами | Уникальные студенты из целевой группы с approved/in_progress/review/completed и активным резервом / все студенты этой группы, которым нужна практика в выбранный период |
| Доля зачтённых практик | Дела с credited / дела с завершённой итоговой оценкой credited или not_credited; показать обе численности |
| Воронка отбора | Уникальные applicationId, достигшие каждого этапа, в когорте по дате первого отклика; не путать с текущим распределением статусов |
| Время согласования | Для согласованных дел: от первой отправки в вуз до первого approved; медиана, единица времени и число дел |
| Практика → предложение работы | Уникальные завершившие практику студенты со связанным последующим offered по job / уникальные завершившие практику студенты выбранной когорты |
| Принятое предложение работы | Отдельно от подтверждённого трудоустройства; принятие предложения не доказывает факт выхода на работу |

Если знаменатель равен нулю — «Недостаточно данных», не 0% и не NaN. По малым выборкам не делать выводы о реальном рынке труда. Публичные агрегаты не позволяют открыть персональное дело. Компания видит только свои предложения, вуз — своих студентов, оператор — учебную совокупность.

CSV: UTF-8, при необходимости BOM для корректного открытия кириллицы, заголовки, период/фильтры и пометка демо. Исключить контактные данные, полные оценки и текст документов. Обезвредить формулы в пользовательских текстовых ячейках, начинающихся с `=`, `+`, `-`, `@`. Скачивание отражает текущий фильтр, а не весь набор.
