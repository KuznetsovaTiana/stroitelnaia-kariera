## SC10 и полный SC02

SC10 выполнен в браузерной среде: сохранённый черновик → другая роль → перезагрузка → возврат; независимый профиль → seed; отмена/подтверждение сброса; чужой ключ остаётся; повреждённое/недоступное хранилище; прямые/неизвестные ссылки; возврат с несохранённым текстом; клавиатура/360 px. Физическая проверка телефона остаётся непроверенной частью SC10.

SC02 выполнен полностью: отклик Анны → предложение компании → принятие/резерв → документы и возврат/новые версии → согласование вуза → демо-дата/начало → задание/замечание/повторная сдача → отчёт/отзыв/замечание/отчёт v2 → зачёт → перезагрузка. Настоящий HTML скачан и открыт; сообщения разрешены внутри дела; второй уникальный зачёт отражается в аналитике. Envelope 63 372 байта, ниже бюджета 1 MiB. Ограничение последнего места/повтор/отмена дополнительно проверены доменно.

## Точные команды

Из корня комплекта, PowerShell:

```powershell
cd app
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npm.cmd run build
npm.cmd run preview -- --port 4175 --strictPort
```

Открыть http://127.0.0.1:4175/#/demo . Во втором терминале:

```powershell
cd app
$env:DEMO_BASE_URL = 'http://127.0.0.1:4175/'
npm.cmd run test:browser
npm.cmd run test:b1
npm.cmd run test:b2
npm.cmd run test:d
$env:DEMO_MOBILE = '1'
npm.cmd run test:c
Remove-Item Env:DEMO_MOBILE
npm.cmd run coverage
npm.cmd run test:static
Remove-Item Env:DEMO_BASE_URL
```

Для чистой установки перед командами: `npm.cmd ci`. Зависимости не менялись; установка в этой приёмке не требовалась. `npm.cmd` обходит локальное ограничение запуска npm.ps1 без изменения ExecutionPolicy. Edge должен быть установлен. test:static самостоятельно использует и освобождает localhost:4176. Все тесты работают во временных контекстах, не сбрасывая браузер пользователя.
