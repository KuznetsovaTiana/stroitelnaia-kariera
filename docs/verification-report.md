## Воспроизведение

Из корня проекта, PowerShell, терминал 1:

```powershell
cd app
npm.cmd run typecheck
npm.cmd run lint
npm.cmd test
npm.cmd run build
npm.cmd run preview -- --port 4185 --strictPort
```

Открыть http://127.0.0.1:4185/#/demo . С установленными зависимостями npm ci не требовался; версии и lockfile существующего проекта сохранены. Для чистого окружения перед командами выполнить npm.cmd ci.

Терминал 2:

```powershell
cd app
$env:DEMO_BASE_URL = 'http://127.0.0.1:4185/'
npm.cmd run test:browser
npm.cmd run test:b1
npm.cmd run test:b2
npm.cmd run test:d
$env:DEMO_MOBILE = '1'
npm.cmd run test:c
Remove-Item Env:DEMO_MOBILE
npm.cmd run test:audit
npm.cmd run test:jury
npm.cmd run test:static
npm.cmd run coverage
Remove-Item Env:DEMO_BASE_URL
```

Для разработки: npm.cmd run dev; production-preview отдаёт app/dist. Для остановки Ctrl+C. test:static сам запускает и останавливает сервер 4176.

Эмуляция viewport: 320, 360, 390, 430, 768 и 1366 px; высота 844 px, desktop 900 px. Дополнительно landscape 844×390 и узкий viewport 683×450; последний не называется настоящим browser zoom 200%.
