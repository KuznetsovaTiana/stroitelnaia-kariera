# Визуальное направление

## Уже выбрано

Тёплый молочный фон и выраженная архитектурная графика. Продукт должен выглядеть самостоятельной строительной платформой. Каркас hh.ru используется как функциональный ориентир, визуальный стиль и тексты не копируются.

## Рабочий вариант для первого макета

| Элемент | Предложение, ещё не финальное утверждение |
|---|---|
| Фон страницы | `#F5F2EB` |
| Карточки | `#FFFDF8` |
| Основной текст и главная кнопка | `#292824`, на кнопке светлый текст |
| Вторичный текст | `#68645B`, проверить контраст на реальном фоне |
| Разделители и сетка | `#D9D2C5`, не использовать для мелкого важного текста |
| Статусы | Небольшие приглушённые индикаторы плюс текст; не полагаться только на цвет |
| Типографика | Читаемый гротеск с кириллицей; для маркировки и координат — моноширинные цифры |
| Ресурсы | Локальные шрифты с подходящей лицензией либо системный стек, SVG/CSS-графика |

Архитектурный характер дают тонкие линии плана, координатная сетка в свободном пространстве, размерные отметки, аккуратные выноски, геометрические схемы. Они не пересекают текст, не мешают формам и не делают интерфейс похожим на перегруженный чертёж. Яркий декоративный акцент не нужен. Фотографии не обязательны.

## Характерный экран S01

Настольная версия: узкая боковая навигация, верхняя строка роли, приветствие тестового студента, главный блок ближайшего действия, компактная шкала практики, образовательный профиль и рекомендации. Показывать одно наиболее важное действие, например «Отправить документы на проверку». На мобильном — одноколоночная композиция, доступная навигация и те же действия.

В первом макете показать карточку практики, две части профиля, статус, кнопку, поле ввода, небольшую таблицу/список и пустое состояние. Затем применить направление к P01 и P02: главная передаёт идею, поиск доказывает удобство.

## Согласование

Предоставить рабочий экран и изображения настольного и мобильного вида. Зафиксировать ответ в decisions/progress. Пока заказчик не согласовал экран, цвета, шрифты, плотность и композиция имеют статус рабочего предложения. Не размножать несогласованную композицию на все кабинеты.

## Общие правила

- Основная единица отступов 4/8 px; использовать единые токены, а не случайные значения по страницам.
- Текст интерфейса обычно 16 px; служебные подписи не мельче 12–14 px; масштаб 200% не ломает действия.
- Клавиатурный фокус хорошо виден; поля подписаны; ошибки связаны с полями; кнопки доступны для нажатия на телефоне.
- На ширине 360 px нет горизонтальной прокрутки всей страницы. Таблицы получают карточечный вид или собственную область прокрутки.
- Подтверждённые учебные сведения, самоописание и текст помощника различаются заголовками и метками происхождения, а не только оттенками.
- На видном месте: «Демонстрация · вымышленные данные». У помощника: «Имитация ИИ». У документа: «Учебный образец».
- Избегать «достоверные данные МГСУ» без уточнения «демонстрационный пример». Не использовать герб/логотип вуза как признак официального партнёрства.
