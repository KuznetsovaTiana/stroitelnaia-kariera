# Маршрут показа жюри · 5–7 минут

Подготовка: `cd app`, `npm.cmd run preview -- --port 4175 --strictPort`. Открыть http://127.0.0.1:4175/#/demo . Нажать «Начать заново» → «Восстановить исходный набор». Не использовать браузерный профиль с важным собственным сценарием. Все ID ниже вымышленные; время практики управляется явно помеченными демо-кнопками.

| Время | Роль / адрес после # | Действия и результат |
|---|---|---|
| 0:00–0:40 | Анна, `/student` | Показать ближайшее действие, образовательный профиль и общий демо-баннер; открыть `/student/education`. Учебные факты имеют источник, студент не правит их напрямую |
| 0:40–1:30 | Анна, `/student/resumes` | Открыть резюме и сценарный помощник. Ответить про учебный проект/собственный вклад, показать предпросмотр; явно назвать имитацией, принять текст только после просмотра |
| 1:30–2:20 | Анна, `/practices/offer_pto_demo` | Посмотреть причины совпадений, выбрать резюме и подтвердить передачу; «Отправить отклик». Перейти по «Отклик уже отправлен» — это снимок версии, а не живое редактирование отправленного резюме |
| 2:20–3:00 | Основной работодатель, `/employer` | Открыть отклик Анны, ввести учебный комментарий, «Предложить место». Вернуться Анной в тот же отклик, «Принять предложение компании» → «Открыть дело практики». Видны один резерв и требования |
| 3:00–3:40 | Анна, созданное дело | Заполнить примечание, «Сохранить условия практики», «Сформировать обязательные документы». Показать поля/источники/версии, скачать HTML. Документ — учебный образец, без электронной подписи |
| 3:40–4:40 | Координатор, `/university/practices/practice_1` | Переключиться на заранее подготовленное дело Марии «Проверка отчёта». Это другое дело, не завершение недель практики Анны за минуту. Показать принятые задания, отчёт/отзыв/историю. «Демо: перейти к окончанию практики», подтвердить; заполнить пояснение итога, «Зафиксировать зачёт» |
| 4:40–5:30 | Оператор, `/operator/reports` | Показать второй уникальный зачёт, фильтр программы/периода и «Экспорт текущей выборки CSV» → «Скачать CSV». Это учебные агрегаты, не статистика реального рынка |
| 5:30–6:30 | Координатор / оператор | Коротко показать `/university/import` с образцом ошибок и предпросмотром без применения; `/operator/integrations` — явно локальная симуляция. Завершить `/demo/about` с границами демо |

Полный SC02 без подготовленного дела занимает дольше: продолжить дело Анны, направить версии документов на проверку и дело в вуз; договор сначала проверяет компания, затем вуз, другие начальные документы — вуз; после возврата формировать новые версии. Координатор согласует дело и подтверждает начало после изменения демо-даты. Компания выдаёт/принимает задание, студент сдаёт результат и отчёт; компания проверяет отчёт, вуз согласует и фиксирует итог после демо-даты окончания. Этот полный путь автоматизирован и пройден `npm.cmd run test:b2`.

После показа перезагрузить: итог/документы остаются. Сброс выполняется только по подтверждению и удаляет исключительно локальное сохранение этого демо. Интернет и реальная модель не участвуют. Для публичного показа требуется отдельный HTTPS-релиз и физическая проверка телефона; localhost не является постоянным адресом.
Подготовленное завершение Марии и второй уникальный зачёт проверяются `npm.cmd run test:jury` в отдельном временном контексте.
