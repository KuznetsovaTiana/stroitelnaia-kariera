# Строительная карьера — комплект для разработки

Версия комплекта: 1.0. Основание: исходное ТЗ от 12.10.2026 и уточнения заказчика в обсуждении.
Назначение: передать Codex достаточный контекст для поэтапной разработки демонстрационного сайта.
Это пакет требований и инструкций. Исходный код приложения создаётся на следующем этапе.

## Как начать

1. Распакуйте архив в отдельную папку. Откройте в VS Code ту папку, в которой лежит `AGENTS.md`.
2. Если папка проекта уже существует, перенесите туда содержимое комплекта, сохраняя существующие файлы. Не заменяйте имеющийся `AGENTS.md` без сравнения.
3. Откройте Codex в этой папке и передайте текст из [первого задания](prompts/01-start.md).
4. Codex изучит комплект, создаст каркас, данные и один характерный экран. Посмотрите экран в браузере и согласуйте визуальное направление.
5. Затем используйте [следующие задания](prompts/02-build.md) по одному этапу. После реализации и проверки — [задание на публикацию](prompts/03-release.md).

На первом этапе никакой оплаты, сервера или подключения языковой модели не требуется. Команды запуска появятся в README приложения после создания каркаса. Не нужно устанавливать зависимости до появления `package.json`.

## Какой результат должен получиться

Самостоятельный адаптивный сайт по постоянной HTTPS-ссылке. Жюри открывает QR-код, выбирает демонстрационную роль и проходит сценарии без регистрации. Приложение работает в браузере, а изменения хранятся локально на устройстве посетителя. Для открытия опубликованного сайта не требуется ChatGPT или включённый компьютер автора.

До 25 октября 2026 года нужна ссылка на проверенную демонстрацию и QR-код. Сначала обеспечить полный путь практики и устойчивый доступ; дальнейшее развитие вести по тому же адресу. Публичная публикация исходного кода и выбор сервиса размещения решаются отдельно.

Код находится в `app/`. Команды запуска и проверки: [README приложения](app/README.md). Для запуска из корня комплекта: `cd app`, `npm ci`, `npm run dev`; открыть http://127.0.0.1:5173/#/student . Сайт на этом этапе не опубликован.
